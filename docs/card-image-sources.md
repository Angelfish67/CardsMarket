# Bildquellen des Kartenkatalogs

Die 18 Standardtypen in [db/brainrot_catalog.json](../db/brainrot_catalog.json)
verwenden externe HTTPS-Bilder aus der öffentlichen Sammlung
[balaboom123/awesome-italian-brainrot](https://github.com/balaboom123/awesome-italian-brainrot).
Die Links sind auf die Revision `22520721659a390cd101b9a096e2e05057d64704` festgelegt.
Die Sammlung benennt Fandom beziehungsweise Namu Wiki in den jeweiligen Dateinamen
als Herkunft; damit wird keine eigene Urheberschaft oder freie Bildlizenz behauptet.

Die App lädt die Bilder direkt im Browser. Es werden keine externen Bilder auf
dem Anwendungsserver heruntergeladen. Bei einem Ladefehler erscheint weiterhin
die Ersatzgrafik. Eigene HTTPS-Bildlinks können im Admin-Panel hinterlegt werden.

Die Seeds legen fehlende Typen an und ergänzen leere Bildfelder bestehender
Standardtypen. Bereits gesetzte Bilder, Werte, Seltenheiten und Aktivstatus bleiben
erhalten. Wer bei einem Standardtyp das Bildfeld leert, erhält beim nächsten
Seed-Lauf wieder das Standardbild.

Kartenbilder verwenden `object-fit: cover`, keine Innenabstände und die volle
Bildfläche. Abweichende Seitenverhältnisse werden zentriert beschnitten, nicht
verzerrt. Rank und Seltenheit liegen darüber. Die Admin-Bildvorschau zeigt weiterhin
das vollständige Motiv.
